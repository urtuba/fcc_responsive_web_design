freeCodeCamp coursework, 2019. Restored in 2026: valid HTML, working responsive layout, no dead media, CI. Original code: tag original-2019.

Certificate: [freeCodeCamp Responsive Web Design](https://www.freecodecamp.org/certification/urtuba/responsive-web-design)

These three projects are part of that certificate.

## Projects

- **Tribute page**: a short tribute to P. T. Barnum.
- **Survey form**: a student feedback form. It sends nothing anywhere.
- **Product landing page**: a landing page for handmade baseball bats, with a header that stacks on small screens.

## Check locally

Open `index.html` in a browser.

To validate the HTML (needs Node 22.22 or newer):

```
npx html-validate@11.16.2 *.html
```
